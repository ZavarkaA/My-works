# diplom
Разработка системы управления заявками сервисного обслуживания объекта


#1 Сотрудники отелей смогут создавать заявки на неисправности, прикреплять описание и фотографии.

#2 Сервисная служба будет получать заявки, обрабатывать их, менять статус и общаться с заявителем через встроенный чат.

#3 Система будет интегрирована с существующей базой данных предприятия через API и использовать уже имеющиеся данные о гостиницах и сотрудниках.


Необходимо создать зависимости

Для работы с фронтом бери страницы по адресу diplom/main/templates/main/

Для стилей, фото и джс - static/main/

ПОсмотри на layout.html - он как шаблон с головой и меню, остальные файлы, наполнение остальных страниц, для примера вставила index.html 

Для того чтобы новые файлы отображались пишешь соответствующее в views.py+main/urls.py

РЕАЛИЗАЦИЯ__________________________
Вариант Б (On-Premise): Вы поставляете систему в виде комплекта файлов (например, Docker-образов). Предприятие разворачивает ее на своих внутренних серверах.

Плюсы: Максимальная безопасность, прямой доступ к внутренним базам данных и API без необходимости настройки VPN.

Минусы: Вы не имеете доступа к системе, обновления нужно будет доставлять предприятию для самостоятельной установки.

Рекомендация для диплома и жизни:
Выберите Вариант Б (On-Premise) с использованием Docker. Это современный стандарт. Вы пишете в дипломе: "Система поставляется в виде Docker-контейнеров, что обеспечивает легкое развертывание на инфраструктуре заказчика, изолированность и масштабируемость." Предприятию достаточно иметь Docker и скопировать ваш образ.
