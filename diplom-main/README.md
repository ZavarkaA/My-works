# Система управления заявками сервисного обслуживания

**Система управления заявками сервисного обслуживания** — веб-приложение, разработанное в рамках дипломного проекта. Предназначено для автоматизации процесса обработки заявок на техническое обслуживание и устранение неисправностей оборудования.

Проект позволяет сотрудникам создавать и отслеживать заявки, назначать исполнителей, контролировать статусы выполнения работ и взаимодействовать друг с другом через встроенный чат.

## Основные возможности

* **Авторизация сотрудников** — система входа с разграничением доступа.
* **Управление заявками** — создание, просмотр и редактирование заявок с описанием проблемы.
* **Категории и статусы** — классификация заявок и отслеживание этапов их выполнения.
* **Назначение исполнителей** — распределение заявок между сотрудниками.
* **История изменений** — сохранение информации об изменениях заявок.
* **Прикрепление фотографий** — возможность добавлять изображения к заявкам.
* **Встроенный чат** — обмен сообщениями между сотрудниками в рамках обработки заявок.
* **REST API** — программный интерфейс для взаимодействия с системой.
* **Docker** — возможность контейнеризации и упрощения развертывания приложения.

## Цель проекта

Разработка системы, которая упрощает работу с заявками на сервисное обслуживание, обеспечивает централизованное хранение информации, повышает прозрачность процесса обработки обращений и позволяет контролировать выполнение технических работ на каждом этапе.

Проект демонстрирует навыки разработки серверной части веб-приложений, работы с базами данных, создания REST API, реализации авторизации и организации взаимодействия между пользователями.
